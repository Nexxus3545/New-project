MWOS Windows Web App

Setup: https://tmc-copino-mwos.vercel.app/download#windows
Open portal: https://tmc-copino-mwos.vercel.app/portal

1. Open the setup page in Microsoft Edge or Google Chrome on Windows.
2. Choose Install MWOS when available, or use the browser menu to install the page as an app.
3. Open MWOS from the Start menu or desktop and sign in.

Use your existing patient or clinic staff account. Internet is required for appointments, records, messages, and telehealth.
These steps install the browser-based MWOS web app. You can also open the portal directly in your browser.
